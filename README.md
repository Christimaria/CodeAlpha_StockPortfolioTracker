# CodeAlpha Stock Portfolio Tracker

## Project Overview
The Stock Portfolio Tracker is a Python program that calculates the total investment value of a user's stock portfolio using predefined stock prices and quantities entered by the user.

The program also exports the portfolio summary to a CSV file.

## Features
- Displays available stock symbols and their predefined prices.
- Accepts stock symbols and share quantities from the user.
- Calculates the investment value of each stock.
- Calculates the total portfolio investment value.
- Validates stock symbols and quantities.
- Exports portfolio details to a CSV file.

## Technologies Used
- Python 3
- Dictionary
- Lists
- Loops and conditional statements
- Exception handling
- CSV file handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python stock_portfolio.py
```

5. Enter stock symbols and quantities.
6. Type `done` to display the summary and save the CSV file.

## Sample Stock Symbols
- AAPL
- TSLA
- GOOGL
- MSFT
- AMZN

**Note:** The stock prices are hardcoded example values and do not represent live market prices.
